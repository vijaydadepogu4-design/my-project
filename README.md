# Cluster Dashboard UI

A modern and responsive **Cluster Dashboard UI** built using **HTML5** and **CSS3**. Inspired by enterprise infrastructure dashboards for monitoring cluster health, resource utilization, and system events.

## ✨ Features

- Enterprise-inspired dashboard interface
- Responsive three-panel layout
- Cluster details overview
- System status monitoring
- Resource utilization dashboard
- Cluster inventory
- Events timeline
- Clean and minimal design

## 🛠️ Tech Stack

- HTML5
- CSS3
- Google Fonts (Inter)

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/cluster-dashboard-ui.git
cd cluster-dashboard-ui
```

Open `index.html` in your browser or run it using **Live Server**.
