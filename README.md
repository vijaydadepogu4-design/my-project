# Cluster Dashboard UI

A modern and responsive **Cluster Dashboard UI** built using **HTML5**, **CSS3**, and **JavaScript**. Inspired by enterprise infrastructure dashboards, the application provides a clean interface for monitoring cluster health, resource utilization, system status, and event activity.

**🌐 Live Demo:** https://vijay4design.github.io/my-project/

## ✨ Features

* Enterprise-inspired dashboard interface
* Responsive three-panel layout
* Cluster overview and health monitoring
* Resource utilization dashboard
* Cluster inventory management
* Events timeline
* Clean, modern, and intuitive user interface

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Google Fonts (Inter)

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/cluster-dashboard-ui.git

cd cluster-dashboard-ui
```

Open `index.html` in your browser or run the project using the **Live Server** extension in Visual Studio Code.
